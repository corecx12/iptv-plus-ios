# IPTV+ für iPhone

Xtream-Codes-Player für iOS (SwiftUI + VLC). Live TV, Filme, Serien, TV-Programm (deutsche Sender), Einstellungen.
VLC spielt jedes Format direkt (AC3, E-AC3, MP2, HEVC, Zeilensprung, MKV).

Gebaut von CoreCX.

## IPA bauen
Jeder Push auf `main` baut über GitHub Actions eine **unsignierte** `IPTVPlus.ipa` (Reiter *Actions* → letzter Lauf → *Artifacts*).

## Installation
Mit Sideloadly oder AltStore und der eigenen Apple-ID signieren und installieren
(kostenlose Apple-ID: alle 7 Tage neu signieren).
